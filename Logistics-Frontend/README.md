# Logistics Exception and Delivery Resolution Platform

A web-based application for managing logistics, shipments, delivery routes, and delivery exceptions.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Java
- Spring Boot
- Spring Security
- Hibernate
- Spring Data JPA

### Database
- MySQL

### Tools
- Visual Studio Code
- Git
- GitHub
- Postman

## Main Modules
- Admin Dashboard
- Customer Management
- Shipment Management
- Route and Delivery Management
- Shipment Tracking
- Exception Management
- Customer Dashboard
- Customer Profile

## Project Purpose
The system helps administrators manage shipments and delivery operations while allowing customers to view their own shipment information.
